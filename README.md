# HTML5, CSS3 and ASP.NET MVC Projects

Coursework and practice projects from learning front-end and server-side web development.

## Contents

- **`html-css/`**: HTML5 and CSS3 exercises.
  - `First Week/`, `Second Week/`, `Third Week/`: weekly exercises (lists, tables, images, CSS styling).
  - `Homework/`: a homework page.
  - `site-pages/`: small site pages such as a login page, a home page and seat selection pages.
  - `starter-page/`: a minimal HTML and CSS starter page.
- **`asp.net mvc/`**: ASP.NET MVC projects.
  - `login-site/`: an MVC site with a login page, an account model and controllers, styled with Bootstrap.
  - `date-practice/`: a small MVC practice project.
  - `aspnet-core-mvc/`: an ASP.NET Core MVC project.

## How to run

- Open any `.html` file in a browser.
- Open the `.sln` file of an MVC project in Visual Studio and run it.
