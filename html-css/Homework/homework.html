        “Hyper Text Markup Language” yani en bilinen adıyla HTML Türkçe ’de “Zengin Metin İşaretleme Dili” olarak 
        adlandırılmaktadır. Bir web sayfasının oluşturulmasında kullanılan HTML, ‘.html’ ya da ‘.htm’ uzantılarıyla 
        ifade edilmektedir. Kodlama dilleriyle sıklıkla karıştırılan HTML, aslında betik bir dildir ve ‘tag’ yani 
        etiket yapısından oluşturmaktadır. Açılan etiketlerin içerisinde yerleştirilen komutlar ile web sayfasının 
        temel yapısını inşa etmekte kullanılan HTML, standart oluşturulmuş herhangi bir metin web tarayıcıda 
        görüntülenmesini sağlamaktadır. “Cascading Style Sheets” yani bilinen adıyla CSS, Türkçe’ de “Basamaklı Biçim 
        Sayfaları ya da Basamaklı Stil Şablonları” olarak adlandırılmaktadır. CSS, HTML tarafından oluşturulan ve web 
        sayfasında gönderilen metinlerin renk, biçim, yazı fontu, arka plan, genişlik ya da yükseklik gibi parametreler 
        ile şekillendirilmesi sağlamaktadır.
